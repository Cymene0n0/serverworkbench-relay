# 测试范围

`bash tests/unit.sh` 验证地址/端口/Token 边界、注入拒绝、固定资产摘要、最小 frps 配置和非 root systemd 配置。测试只使用 `mktemp` 创建的隔离目录，不修改真实配置、用户或服务。

`bash tests/run.sh` 运行完整的 Linux x86_64 测试。它下载并校验官方固定版本 frps/frpc；也可设置 `SWB_RELAY_FIXTURE_ARCHIVE=/path/to/frp_0.71.1_linux_amd64.tar.gz` 复用已下载的同一官方包，摘要校验仍然执行。ARM64 当前验证资产固定摘要与参数，尚未实机运行此套件。

生命周期测试在带专用标记的 `/tmp` 目录内运行安装、重复安装、升级失败回滚、显式换 CA、卸载和重装。测试模式内部模拟系统服务、账户和包管理，不修改真实 systemd 或 Linux 用户。证书生成、OpenSSL 验证和官方 Linux 二进制执行均是真实操作。

真实 TLS 部分使用生产代码生成的证书、随机回环端口和官方 frps/frpc，完成128KB随机二进制数据往返，并验证错误 Token、CA 和证书名称被拒绝。它们不代替公网、中转机防火墙、云安全组或真实游戏玩家加入验收。

不要在生产服务器上运行带测试根路径或模拟系统命令的生命周期测试。正常安装入口不提供通用的路径改写选项。

`tests/systemd-smoke.sh` 只允许在临时 GitHub-hosted Linux runner 内运行。Ubuntu24.04 CI 会实际安装生产路径的 systemd 服务，验证控制端口被占用时必须失败、首次激活失败后可以卸载并保留凭据重装、专用账户与文件权限、TLS 证书握手、sudo 导出的公钥包归属、重复安装不改凭据且不重启，以及卸载停止服务并保留凭据。这个测试会修改 runner 的系统服务和账户，不能在个人电脑 WSL 或生产主机运行。它不修改防火墙，也不代表公网玩家已经连接成功。
