# 测试报告

本项目是 Linux 中转部署工具；Windows 开服工坊及游戏世界不属于此仓库的测试数据。测试没有启动、升级或修改原 tModLoader 世界。

## 本机实测

记录日期：2026-10-31（北京时间）。宿主为 Windows 11，测试环境为现有 WSL Ubuntu 24.04.3 LTS、Linux x86_64、Bash、Python 3.12.3、OpenSSL 3.0.13。使用 frp 官方 0.71.1 Linux amd64 发行包，先核对仓库固定 SHA256 再运行。

生命周期测试在带标记的独立 `/tmp` 目录运行；systemd、用户和包管理操作使用测试替身。未修改宿主防火墙、时区、路由、代理或实际 Linux 系统服务。因此本机生命周期测试通过，不等于真实 VPS 部署通过。

真实转发测试使用官方 frps/frpc、实际 OpenSSL 生成的证书和回环 TCP 端口，传输并比对 128KB 随机二进制数据；同时验证错误 Token、错误 CA、错误证书名称无法登录。它证明本机 TLS 隧道可以传输有效载荷，不代表公网游戏玩家已加入。

覆盖项目：

- 地址、端口、Token 校验，Shell/TOML 模板注入拒绝，固定上游资产摘要。
- 首次安装、重复安装、保留 Token/CA 的升级、失败后的文件与服务状态恢复。
- 未启动安装、只读 dry-run、并发管理锁、显式 CA 轮换。
- 卸载、重复卸载、保留凭据后重装；停止或禁用失败时拒绝移除活动组件。
- 首次激活失败后 unit 已移除的残留安装，允许在确认未加载、未运行后卸载。
- 受管理目录身份检查、符号链接拒绝、导出路径替换攻击拒绝。
- 默认输出和客户端导出无真实 Token、无私钥；CA 签发私钥不会提交到安装目录。
- 官方 frps 配置验证及 TLS 数据往返、错误认证与证书校验拒绝。
- 安装和重复安装在实际运行模式中要求本机 TLS 证书校验就绪；测试模式不会冒充此生产环境检查。

最终本机复测：12 组单元测试、15 组生命周期/真实 TLS 测试，合计 **27 组通过**。Bash 语法检查、ShellCheck 0.9、Python 编译与引导器 SHA256 一致性检查均通过。失败回滚使用不同的旧管理脚本、库、包装入口和许可证标记，验证确实恢复旧内容；首次激活失败后也验证卸载残留与保留凭据重装。

已测核心 SHA256：`relay.sh` 为 `7c4ba4f6acb311b17900284371dcbb1e4c03f022e8a79ffa0608a9cf5ebc4c74`。CI 运行结果将在发布验证后追加。

## 未验证项

- 用户自己的公网 Linux VPS、云安全组、运营商链路和异地玩家实际加入。
- Linux ARM64 原生执行；当前仅固定官方 ARM64 包地址及 SHA256。
- UFW/firewalld 的真实规则修改和部分失败恢复；默认安装不更改防火墙。
- 长时间运行、证书跨年续期及大规模并发连接。
- 本版仅提供 IPv4 TCP 中转；不支持直接以 IPv6 节点地址部署。

安装后应先确认服务与客户端穿透状态，再由异地实际游戏客户端连接公网游戏端口。单凭服务活动、进程存在、端口打开或代理注册，不计为实际开服成功。
